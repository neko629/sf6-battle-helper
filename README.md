# SF6 Battle Helper

一个仅处理《Street Fighter 6》排位赛对战确认窗口的 Windows 小工具。它不会在比赛中发送输入。

工作流程：

1. 识别“已匹配到排位赛的对手”提示并按 `Tab`。
2. 识别对手是有线还是 Wi-Fi，并读取彩色信号格数。
3. 根据“允许 Wi-Fi”和“最低信号格数”自动选择“参战”或“取消”。

## 使用

建议将游戏设置为无边框窗口或窗口模式，并保持 Windows 显示缩放不变。

```powershell
cd G:\coding_workspace\sf6-battle-helper
python -m pip install -r requirements.txt
python main.py
```

界面中设置：

- **允许 Wi-Fi 对手**：关闭时所有 Wi-Fi 对手都会被拒绝。
- **最低信号格数**：低于该格数时拒绝。
- **游戏窗口标题包含**：默认同时兼容 `Street Fighter 6` 和 `StreetFighter6`。
- **按键**：默认首次确认 `Tab`；详情页接受为 `F`，拒绝为 `S` 后 `F`。

点击“开始监控”后，按 **F8** 可随时紧急停止。工具仅在匹配到指定标题的游戏窗口处于前台时截图和发送按键。

## EXE 版本

可直接运行 `dist\SF6-Battle-Helper.exe`，无需安装 Python。GUI 中可以选择 Wi-Fi 策略、最低信号格数、窗口标题和操作按键。配置保存在 EXE 同目录的 `config.json`。

重新构建时双击 `build.bat`。构建产物仍在 `dist` 目录。

## 识别调试

如果实际游戏画面无法正确识别，可点击“保存调试截图”，文件会写入 `debug-captures`。把该截图补充到 `img-examples` 后可以继续调整识别参数。

运行离线测试：

```powershell
python -m unittest discover -s tests -v
```

## 限制

- 当前样本来自中文界面；首次提示识别使用用户提供的中文截图模板。
- 游戏分辨率或 UI 缩放变化很大时，模板匹配可能需要新样本。
- 若游戏以管理员身份运行，本工具也需要相同权限，否则 Windows 可能阻止输入。
- 1.0.1 起会同时按窗口标题和 `StreetFighter6.exe` 进程名识别游戏，并使用扫描码输入以提高游戏兼容性。
- 1.0.2 起 EXE 会请求管理员权限，避免 Windows 权限隔离导致截图成功但按键被静默丢弃。
- 1.0.3 将首次提示限制在屏幕下方并要求连续两帧确认；详情页确认键统一为 `Tab`。
- 1.0.4 要求网络图标外层必须存在大面积紫色确认弹窗，排除设置页角色和 UI 色块误报。
- 1.0.5 按 SF6 PC 菜单固定键位改为 `F` 确认、`WASD` 导航；日志只声明操作已发送。
- 1.0.6 网络识别同时校验“参战/取消”两条居中按钮边框，排除紫红色比赛结果页误报。
- 1.0.7 使用严格顺序状态机；只有第一步识别并发送 Tab 后的 8 秒内，第二步网络判断才会生效。
